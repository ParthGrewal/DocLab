📌 Overview

DocLab is a full-stack web application designed to simplify healthcare access by enabling users to book doctor appointments, manage schedules, and streamline patient-doctor interactions efficiently.

It provides a seamless digital experience for both patients and healthcare providers.

🚀 Features
👨‍⚕️ Doctor listing and profiles
📅 Appointment booking system
🔐 User authentication and authorization
🧾 Patient data management
⏱ Real-time availability tracking
📊 Dashboard for doctors/admin
💻 Responsive UI for all devices

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/ParthGrewal/DocLab.git
cd DocLab
2️⃣ Install dependencies

Backend:

cd backend
npm install

Frontend:

cd frontend
npm install
3️⃣ Run the project

Backend:

npm start

Frontend:

npm run dev
